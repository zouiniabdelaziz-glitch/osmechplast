# Register öffentlich verwendeter Unternehmensbehauptungen

Stand: 2026-08-29  
Zweck: Prüfbasis für Phase 0 des Website-Umsetzungsplans. Dieses Register ist keine neue Marketingstrategie und keine Freigabe zusätzlicher Aussagen.

## Statusdefinitionen

- **bestätigt:** durch Inhaberentscheidung, verbindlichen Projektkontext oder ausdrücklich freigegebene Geschäftsgrundlage bestätigt.
- **geplant:** darf ausschließlich als geplant bezeichnet werden; keine Darstellung als bestehender Zustand.
- **intern zu prüfen:** im Code vorhanden, aber für weitere Verwendung ist ein Inhaber-/Fertigungs-/Rechtsbeleg erforderlich.
- **entfernen:** darf öffentlich nicht als Leistungsversprechen verwendet werden; technische Entfernung erfolgt nur in der dafür freigegebenen Phase.

## Prüfregel für Änderungen

Vor jeder Text-, Schema-, Meta-, Profil- oder Übersetzungsänderung muss die verwendete Aussage einer Registerzeile zugeordnet sein. **Intern zu prüfen** und **entfernen** dürfen nicht als neue positive Leistungsbehauptung ausgerollt werden.
