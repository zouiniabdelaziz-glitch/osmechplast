# Monatliche SEO-Kontrolle

Stand: 2026-07-24

## Monatlicher Rhythmus

Einmal pro Monat wird geprüft, ob die Website technisch erreichbar, indexierbar und für Anfragen nutzbar ist.

## Prüfliste

1. Öffentliche Seiten öffnen: Start, Leistungen, Qualität, Technologie, Unternehmen, Werkstoffe, Kontakt, Impressum.
2. Sitemap abrufen: https://osmechplast.com/sitemap.xml
3. robots.txt abrufen: https://osmechplast.com/robots.txt
4. Formular testen: Anfrage mit Testdaten nur in abgestimmter Testphase senden.
5. Search Console prüfen, sobald Zugriff vorhanden ist: Indexierung, Sitemap, Suchanfragen, Fehler.
6. Analytics prüfen, sobald Consent-Daten vorhanden sind: Kontakt-CTA, Telefon, E-Mail, Anfrageversuch, erfolgreiche Anfrage.
7. Neue oder verlorene Backlinks prüfen, sobald Search Console oder ein SEO-Tool vorhanden ist.
8. Neue Inhalte gegen Faktenregel prüfen: keine erfundenen Zertifikate, Lieferzeiten, Toleranzen oder Referenzen.

## Ergebnis dokumentieren

- Datum
- geprüfte Seiten
- gefundene Fehler
- erledigte Korrekturen
- offene Punkte
- nächste Entscheidung
